The purpose of this file is for me to remember key concepts in my project.

The rules of the game:
    - no row or column can have more than 1 occurrence of a number
    - black nodes can't be adjacent horizontally or vertically
    - black nodes can be adjacent diagonally
    - the graph where the vertices are the remaining white nodes must be connected

In DIMACS CNF each atomic formula is represented as an integer. The atomic 
formula's negation is it's negative value. Each clause ends with a 0 => no atomic 
formula can have it as it's representation.
    => I will have to represent the nodes as non-zero integers.
    ... I decide that if a node is black than it has a negative value

Syntax of the DIMACS CNF:
p cnf {number of atomic formulas} {number of clauses}
{atomic formula} {atomic formula} ... 0    
{atomic formula} {atomic formula} ... 0
...
each row is a new clause and 

Rules in CNF:
~ ... negation = white node

    1)  Want to avoid having the same number as white multiple times in a row or column.
        Each number can occur as white at most once in each row and column. If there are
        k occurrences then k-1 must be black

        Bad: p1 AND p2 where p1 and p2 are white and the same number and on the same axis
        Good: ~(p1 AND p2) = ~p1 OR ~p2

    2)  Want to avoid: (~p1 AND ~p2) where p1 and p2 are neighbours.
        To avoid it we negate it and make it a rule:
        ~(~p1 AND ~p2) = p1 OR p2

    3)  want to avoid making white islands.
